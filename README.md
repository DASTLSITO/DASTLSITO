#### 🚀 SAT-NOW — Founder & Backend Developer
**Feb. 2026 — Present**

Building a backend platform for automated fiscal reconciliation in Mexico.

SAT-NOW retrieves invoices and tax returns from Mexico's tax authority (**SAT**) and compares tax records against financial data to detect potential overpayments and underpayments.

The backend is designed around **Clean Architecture** and exposes its functionality through a secure REST API built with **ASP.NET Core** and **ASP.NET Identity**. Data extraction combines a Selenium-based scraping engine with SAT web services, while persistence is handled with PostgreSQL and Entity Framework Core.

The solution is fully containerized and designed for cloud deployment.

**Technologies:** C#, ASP.NET Core, Entity Framework Core, PostgreSQL, Selenium, Docker, ASP.NET Identity, AWS.
